When a detected outro/credits ends before the episode ends, mark the remaining portion as a Preview segment. Requires credits fingerprinting. Tune the min/max thresholds on the Detection tab.
An episode with no intro of its own can still match an incidental music cue shared with another episode, producing a segment at an arbitrary position. Discards intros and outros that sit where almost no other episode in the season has one – intros measured from the start of the file, outros from the end. Seasons with no dominant position are left untouched, so shows whose placement genuinely varies are unaffected.

Refinement

Snap detected boundaries to silence gaps or keyframes for cleaner cuts.

Silence Snapping
Snap segment boundaries to nearby silence gaps for more natural transitions.
Noise threshold in dB for silence detection (default: -50).
Minimum silence duration in seconds to be considered a gap (default: 0.33).
Inward search window (toward segment center) for silence snapping (default: 5.0).
Outward search window (away from segment center) for silence snapping (default: 2.0).
Chapter Snapping
Snap segment boundaries to nearby chapter markers, which are usually more precise than detected boundaries.

Keyframe Snapping

Black Frame

ffmpeg-based black-frame detection settings.

Black Frame Settings
Frames are downscaled to this height before analysis. Lower = faster. Uses GPU-side scaling when hardware acceleration is available.
Percentage of a frame that must be black for it to count (default: 90). Changing this requires "Re-analyze Black Frames".
Shortest run of black frames treated as a segment boundary (default: 500). Applied to cached samples, so no re-scan is needed.
Clear all cached black frame data and re-analyze on the next task run. Useful after changing the analysis resolution. Resets automatically.

Chromaprint

Audio-fingerprint settings used for cross-episode intro and credits matching.

Credits Fingerprinting
Compare audio fingerprints from the end of episodes to detect credits/outro segments.
Duration from the end of the episode to fingerprint for credits detection (default: 240).
Probe the actual audio stream duration via ffprobe before locating the credits region. Guards against MKV containers whose duration is inflated by subtitle tracks that run past the audio/video (default: on).
Matching
Audio sample rate used for fingerprinting (default: 22050). Changing this regenerates every fingerprint.
How many of the 32 bits per fingerprint point may differ and still count as a match (default: 6). Lower is stricter.
Largest gap between matching points before a matched run is broken (default: 3.5).
Tolerance when looking up candidate alignments (default: 2). Higher finds more alignments but is slower.
The minimum match length is driven by Minimum Intro Duration (intro pass) and Minimum Outro Duration (credits pass) on the Detection tab.
